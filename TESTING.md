# Testing AdvanCare

The test guide is in two files:

- **[TESTING-APP.md](TESTING-APP.md)** — the families' phone app and caregiver mode (sign-up, profile, the 7 services, requests, reports, assistant, caregiver shift).
- **[TESTING-DASHBOARD.md](TESTING-DASHBOARD.md)** — the staff console (Overview dashboard, inviting Admins, adding caregivers, assigning, scheduling, payments, clients, reports, audit log).

Suggested order: dashboard part A (set up staff and caregiver) → app part B (family books) → dashboard part C (staff handle it) → app part D (caregiver does the shift, next day).
